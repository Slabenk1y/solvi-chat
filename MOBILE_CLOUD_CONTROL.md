# SOVLI: запуск и управление с телефона

## Главное

Телефон не может включить выключенный ноутбук. Чтобы SOVLI был доступен независимо от ноутбука, сам Node.js сервер должен работать в облаке. Для этой сборки подготовлен Render Blueprint.

## Первоначальная настройка

1. Залить проект в GitHub-репозиторий (нужны все файлы, а не только `server.js`).
2. Открыть Render с телефона и создать сервис через Blueprint из этого репозитория.
3. Подтвердить платный Starter web service и persistent disk. Без постоянного диска SQLite и загрузки не гарантированно сохранятся после redeploy.
4. Ввести Render API key в секретное поле Blueprint.
5. После первого запуска зарегистрировать аккаунт и задать `OWNER_PUBLIC_ID` в Render Environment.
6. Добавить GitHub repository secrets `RENDER_API_KEY` и `RENDER_SERVICE_ID`.

## Повседневное управление

Открой `https://<твой-домен>/owner`, войди как владелец, затем добавь страницу на главный экран браузера. Вкладка «Облачный сервер» проверяет Render и позволяет перезапустить работающий сервис.

Если сервис полностью suspended и сайт не открывается, запускай его извне: GitHub → Actions → SOVLI cloud control → Run workflow → `resume`. Для остановки выбери `suspend`. Эта GitHub Actions команда работает независимо от SOVLI.

## Важно

- Не отправляй Render API key, GitHub secrets, JWT secret или invite code в чат.
- Не используй бесплатный ephemeral filesystem для единственной SQLite-базы.
- Установка приложения на главный экран не даёт телефону доступ к Node.js процессам ноутбука; управление сервером выполняется через облачного провайдера.
