Облачный сервер

Когда SOVLI размещён в Render, он работает независимо от твоего компьютера. Эту страницу можно добавить на главный экран телефона.

RENDER CONTROL PLANE

Состояние облака

Не проверено
Нажми «Проверить облако», чтобы получить состояние Render.
Запуск через GitHub Actions ↗

Ключ Render API хранится только на сервере и никогда не отправляется в браузер.

Если сервис остановлен

Если Render-сервис полностью приостановлен, сама панель SOVLI недоступна. Возобновить его можно с телефона через Render Dashboard → Resume или GitHub Actions → SOVLI cloud control. API-ключ Render не хранится в браузере.

Открыть Render Dashboard ↗Открыть GitHub Actions ↗

Как добавить на телефон

  1. Открой эту страницу в Chrome или Safari.
  2. Открой меню браузера.
  3. Выбери «Добавить на главный экран» или «Установить приложение».
  4. Открывай SOVLI Owner как отдельное приложение.
