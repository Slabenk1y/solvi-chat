# SOVLI v1.2.0

SOVLI — международная платформа случайных разговоров 1-на-1. Эта сборка сохраняет локальный Windows-режим и добавляет подготовку к постоянному облачному размещению с мобильной PWA-панелью владельца.

## Два способа использования

### Облако — если хочешь запускать SOVLI с телефона без ноутбука

Рекомендуемый вариант — Render Web Service с постоянным диском. После первого deploy сервер работает в облаке независимо от домашнего компьютера; сайт, чат и `/owner` доступны по HTTPS. С телефона можно проверять сервис и перезапускать его. Если сервис полностью остановлен, возобнови его через Render Dashboard или GitHub Actions.

Полная инструкция для смартфона: **[DEPLOY_FROM_PHONE.md](DEPLOY_FROM_PHONE.md)**.

### Локально — тестирование на Windows

1. Установи Node.js 22.16 или новее.
2. Распакуй архив в отдельную папку.
3. Запусти `start.bat`.
4. Открой `http://localhost:3000`.
5. Для телефона в той же Wi-Fi-сети используй LAN IP, который показывает BAT.

Локальный сервер работает, пока включён компьютер и открыто окно Node. Временный `start-public.bat` с Cloudflare Quick Tunnel — только для краткого теста, не для постоянной публикации.

## Мобильная панель владельца

После входа постоянным аккаунтом владельца открой `/owner`. Панель адаптируется под телефон и может быть установлена через меню браузера → «Добавить на главный экран». Доступны пользователи, балансы, подписки, роли, ограничения, промокоды, метаданные активных диалогов, жалобы, аудит и управление облачным Render-сервисом.

Ключ Render API хранится только в серверных переменных окружения. Он никогда не отдаётся браузеру.

## Ключевые функции платформы

- Регистрация по уникальному нику и паролю; гостевой профиль на 24 часа.
- Случайный поиск по языкам и интересам, отмена и следующий собеседник.
- Чат 1-на-1 через Socket.IO: текст, ответы, реакции, стикеры, фото и голосовые вложения.
- Профиль с описанием, встроенным или собственным аватаром, ролью, привилегией и статистикой.
- Магазин: 57 предметов, 12 коллекций, предпросмотр, покупка, инвентарь и экипировка.
- Экономика: 1 токен за полную минуту, когда оба участника подключены к одному активному диалогу. Оба участника получают по 1 токену.
- Новые аккаунты и гости начинают с 0 токенов. Ежедневных бонусов нет.
- VIP/Premium, закрытый публичный тест по коду приглашения, блокировки, жалобы и управление сессиями.
- Маскот «Сосис-Мышь» с лёгкой SVG/CSS-анимацией.

## Важные ограничения

- Возрастная проверка, разделение несовершеннолетних и взрослых и полноценная production-модерация ещё не завершены. Это закрытая тестовая версия; не публикуй invite code открыто.
- Реальные платежи, пополнение токенов за деньги, E2EE, голосовые/видеозвонки и push-уведомления не реализованы.
- SQLite на Render хранится на одном persistent disk и работает в одном экземпляре. Для горизонтального масштабирования потребуется PostgreSQL и внешнее хранилище медиа.
- Локальная база не переносится в облако автоматически. Для миграции нужны `data/orbit.sqlite`, `data/.jwt-secret` и каталоги загруженных файлов с прежнего компьютера.

## Проверки

```bash
npm run check
npm run verify
npm run doctor
npm test
```

`npm run check` и `npm run verify` проходят статические проверки. Полный runtime/двухклиентский Socket.IO тест в среде подготовки не был выполнен из-за недоступности npm registry. На первом Render deploy проверяй Deploy Logs и `/api/health`.
